## About this entry

The line is an out-of-office reply in miniature, which is exactly
the joke the bounty asks for. It opens with the polite thank-you
every auto-reply must have, so the reader gets the form before the
punchline even arrives. Then it admits the truth: the writer is
avoiding eye contact with the inbox and will only reply when the
guilt becomes unbearable. That is inbox life in one sentence, a
formal ritual broken by a confession everyone recognises at once.
The line is a single sentence, it needs no explanation, and it stays
well inside the one hundred and fifty nine character cap. The program
holds the line, checks it against that cap, and writes it to
/output/entry.txt exactly as the bounty requires.

## Run it

```sh
python3 main.py
```

This writes the one line to `/output/entry.txt`.
